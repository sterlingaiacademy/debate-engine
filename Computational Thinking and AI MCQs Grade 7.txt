Question 1

Question 4
Scenario: Consider the following array/list of integers:
Data = [14, 7, 22, 35, 18, 40]
A programmer executes this pseudocode:
Set Count = 0 FOR EACH item IN Data:     IF (item > 20) AND (item % 2 == 0) THEN         Set Count = Count + 1     END IF END FOR OUTPUT Count
What is the final output of Count?
A) 1
B) 2
C) 3
D) 4
Correct Answer: B) 2
Explanation: The condition checks if the number is greater than 20 AND even (item % 2 == 0).
- 14: Not > 20
- 7: Not > 20
- 22: > 20 and even (TRUE, Count = 1)
- 35: > 20 but odd (FALSE)
- 18: Not > 20
- 40: > 20 and even (TRUE, Count = 2)
Question 5

Term(1) = 3
Term(n) = Term(n-1) * 2 - 1 for $n > 1$
What is the value of Term(4)?
A) 9
B) 17
C) 33
D) 25
Correct Answer: B) 17
Explanation:
- Term(1) = 3
- Term(2) = $(3 \times 2) - 1 = 5$
- Term(3) = $(5 \times 2) - 1 = 9$
- Term(4) = $(9 \times 2) - 1 = 17$
Question 6
Scenario: A computer scientist compares two algorithms designed to search through a phone book of 1,000,000 sorted entries:
	•	Algorithm A (Linear Search): Checks entries sequentially from start to finish. In the worst case, it takes 1,000,000 operations.
	•	Algorithm B (Binary Search): Repeatedly divides the search interval in half. In the worst case, it takes approximately 20 operations ($log_2(1,000,000)$).
Why is Binary Search exponentially faster than Linear Search for sorted datasets?
A) Binary search uses parallel processors to check all items simultaneously.
B) Binary search eliminates half of the remaining dataset with each single comparison.
C) Linear search skips items at random intervals.
D) Binary search changes the underlying numbers into text strings.
Correct Answer: B) Binary search eliminates half of the remaining dataset with each single comparison.
Explanation: Binary search operates on sorted data by comparing the target with the middle element, immediately discarding half of the remaining items in each step ($O(\log n)$ logarithmic efficiency).
Question 7
Scenario: A developer builds a smartphone app to measure daily water intake. The application uses this conditional block:
IF WaterIntake >= 2500 THEN     Display "Goal Reached" ELSE IF WaterIntake >= 1500 THEN     Display "Good Effort" ELSE     Display "Drink More Water" END IF
If a user drinks exactly 2,500 mL of water, what message will be displayed, and why?
A) "Good Effort" because 2500 is the upper limit.
B) "Goal Reached" because the condition WaterIntake >= 2500 evaluates to TRUE first.
C) Both "Goal Reached" and "Good Effort" will print.
D) "Drink More Water" because the condition requires strict inequality.
Correct Answer: B) "Goal Reached" because the condition WaterIntake >= 2500 evaluates to TRUE first.
Explanation: The >= operator includes equal values. Since 2500 equals 2500, the first branch evaluates to TRUE and executes, short-circuiting the rest of the ELSE IF chain.
Question 8
Scenario: Consider this pseudocode procedure designed to swap the values of two variables, X and Y:
Set X = 10 Set Y = 25 Set Temp = X Set X = Y Set Y = Temp
Why is the temporary variable Temp necessary in this algorithm?
A) Without Temp, setting X = Y would overwrite the original value of X, causing its initial value to be lost.
B) Computer memory cannot assign values directly between two primary variables.
C) Temp converts integer variables into floating-point numbers.
D) It prevents a syntax error in the compiler.
Correct Answer: A) Without Temp, setting X = Y would overwrite the original value of X, causing its initial value to be lost.
Explanation: Reassigning X = Y immediately overwrites the memory location of X with Y's value. Storing X's original value in Temp preserves it so it can later be assigned to Y.
Question 9
Scenario: Trace the value of Result in the following loop structure:
Set Result = 0 FOR i = 1 TO 4:     FOR j = 1 TO i:         Set Result = Result + 1     END FOR END FOR OUTPUT Result
What is the final value of Result?
A) 4
B) 10
C) 16
D) 8
Correct Answer: B) 10
Explanation: The inner loop runs $i$ times for each iteration of $i$:
- $i=1$: inner loop runs 1 time (Result = 1)
- $i=2$: inner loop runs 2 times (Result = 1+2 = 3)
- $i=3$: inner loop runs 3 times (Result = 3+3 = 6)
- $i=4$: inner loop runs 4 times (Result = 6+4 = 10)
Question 10
Scenario: An e-learning platform records test scores. A programmer writes a sorting routine. During testing with an input list [5, 2, 8, 1, 9], the output produces [1, 2, 5, 8]. The number 9 was completely dropped.
What type of error is this, and what is the best debugging strategy?
A) Syntax Error; fix variable capitalization.
B) Logic Error; trace loop boundary conditions (e.g., array index upper bound) step-by-step.
C) Hardware Error; increase motherboard memory.
D) Runtime Overflow; convert numbers to text.
Correct Answer: B) Logic Error; trace loop boundary conditions (e.g., array index upper bound) step-by-step.
Explanation: The code executes without crashing but yields incorrect results (dropping the last element). This is a logic error, typically caused by an off-by-one boundary condition in loop indexing (e.g., stopping at length - 1 instead of length).

Question 12
Scenario: In computer science, modular programming breaks programs into independent functions. Consider the two pseudocode implementations below:
Program A: Writes 50 lines of duplicate code 10 different times throughout the main script.
Program B: Defines a single function CalculateTax(price) once, and calls CalculateTax(price) 10 times in the main script.
What is the primary advantage of Program B's design?
A) Program B improves maintainability and reusability, making bugs easier to fix in one central location.
B) Program B allows the computer to run without an operating system.
C) Program B encrypts the source code so users cannot read it.

Question 13
Scenario: A digital temperature control system uses two sensors ($S_1$ and $S_2$) and a backup safety switch ($B$). The system triggers a cooling fan ($F = 1$) according to the following Boolean logic expression:
F = (S1 AND S2) OR B
In which of the following states will the fan ($F$) NOT turn on ($F = 0$)?
A) $S_1 = 1, S_2 = 1, B = 0$
B) $S_1 = 0, S_2 = 0, B = 1$
C) $S_1 = 1, S_2 = 0, B = 0$
D) $S_1 = 1, S_2 = 1, B = 1$
Correct Answer: C) $S_1 = 1, S_2 = 0, B = 0$
Explanation: Evaluate C: $S_1 \text{ AND } S_2 = 1 \text{ AND } 0 = 0$. Then $(0) \text{ OR } B = 0 \text{ OR } 0 = 0$. The fan remains off ($F=0$). In all other options, at least one part of the OR statement evaluates to 1.

Question 14
Scenario: A spam detection AI model classifies incoming emails as "Spam" or "Not Spam". During training, the developers evaluate the model using a confusion matrix with 10,000 test emails:
	•	True Positives (Correctly identified Spam): 1,800
	•	False Positives (Legitimate emails incorrectly marked as Spam): 200
	•	True Negatives (Correctly identified Legitimate): 7,900
	•	False Negatives (Spam emails missed by filter): 100
What is the Precision of the spam filter, defined as: $\frac{\text{True Positives}}{\text{True Positives} + \text{False Positives}}$?
A) 90%
B) 95%
C) 80%
D) 99%
Correct Answer: A) 90%
Explanation: $\text{Precision} = \frac{1800}{1800 + 200} = \frac{1800}{2000} = 0.90 \text{ or } 90\%$. Precision measures how accurate the model is when it predicts a positive class.
