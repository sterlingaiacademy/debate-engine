Section 1: Algorithmic Complexity, Data Structures & Logic Systems
Question 1
Scenario: A global logistics company manages a routing system for 100,000 delivery trucks. To compute the shortest delivery paths across connected roads, engineers model the road network as nodes (intersections) and edges (roads with distance weights). They choose Dijkstra's algorithm over checking every possible path sequentially.
Which computational thinking process allows engineers to abstract a physical map into a graph data structure to apply pathfinding algorithms?
A) Pattern Synthesis
B) Data Representation and Graph Abstraction
C) Hardware Paging
D) Heuristic Encryption
Correct Answer: B) Data Representation and Graph Abstraction
Explanation: Abstracting a real-world system into a formal graph (nodes and weighted edges) strips away unnecessary physical details (like scenery or building names) and retains only the topological data needed to execute graph-search algorithms.

What core computational thinking pillar was critical in formulating this automated defense?
A) Pattern Recognition
B) Binary Decomposition

D) Loop Normalization
Correct Answer: A) Pattern Recognition

Question 3
Scenario: A computer scientist evaluates two sorting algorithms acting on an array of $n = 1,000,000$ elements:
	•	Algorithm A (Bubble Sort): Time complexity of $O(n^2)$, requiring roughly $1,000,000,000,000$ operations.
	•	Algorithm B (Merge Sort): Time complexity of $O(n \log_2 n)$, requiring roughly $20,000,000$ operations.
If a processor executes 1,000,000 operations per second, how much faster will Algorithm B complete the task compared to Algorithm A?
A) Algorithm B finishes in ~20 seconds; Algorithm A takes ~1,000,000 seconds (about 11.5 days).
B) Both algorithms finish in the exact same time because they process the same data size.
C) Algorithm A finishes in 2 seconds; Algorithm B finishes in 20 seconds.
D) Algorithm B takes 11.5 days; Algorithm A takes 20 seconds.
Correct Answer: A) Algorithm B finishes in ~20 seconds; Algorithm A takes ~1,000,000 seconds (about 11.5 days).
Explanation: At $10^6$ ops/sec: Algorithm B takes $\frac{20,000,000}{1,000,000} = 20$ seconds. Algorithm A takes $\frac{1,000,000,000,000}{1,000,000} = 1,000,000$ seconds ($\approx 11.57$ days). This demonstrates logarithmic vs. quadratic asymptotic growth ($O(n \log n)$ vs $O(n^2)$).
Question 4
Scenario: Trace the output of the following pseudocode function implementing a recursive calculation:
FUNCTION Mystery(n):     IF n <= 1 THEN         RETURN 1     ELSE         RETURN n * Mystery(n - 1)     END IF END FUNCTION  OUTPUT Mystery(5)
What is the return value of Mystery(5)?
A) 15
B) 120
C) 25
D) 720
Correct Answer: B) 120
Explanation: This algorithm calculates the factorial ($n!$):
$\text{Mystery}(5) = 5 \times \text{Mystery}(4) = 5 \times 4 \times 3 \times 2 \times 1 = 120$.
Question 5
Scenario: Consider a Stack data structure (Last In, First Out - LIFO) and a Queue data structure (First In, First Out - FIFO). A programmer performs these operations:
Push(Stack, 10) Push(Stack, 20) Enqueue(Queue, 10) Enqueue(Queue, 20)  Set X = Pop(Stack) Set Y = Dequeue(Queue)
What are the final values of X and Y?
A) $X = 10, Y = 10$
B) $X = 20, Y = 10$
C) $X = 10, Y = 20$
D) $X = 20, Y = 20$
Correct Answer: B) $X = 20, Y = 10$
Explanation: A stack operates as LIFO, so Pop() removes the last item added ($20$). A queue operates as FIFO, so Dequeue() removes the first item added ($10$).
Question 6
Scenario: An engineer designs a logic circuit for an automated greenhouse window. The window opens ($W = 1$) only when the internal temperature is High ($T = 1$) AND the rain sensor is Dry ($R = 0$), OR when a manual override switch is Active ($M = 1$).
Which Boolean logic expression correctly models this system?
A) $W = (T \text{ AND } R) \text{ OR } M$
B) $W = (T \text{ AND } (\text{NOT } R)) \text{ OR } M$
C) $W = (T \text{ OR } R) \text{ AND } (\text{NOT } M)$
D) $W = (\text{NOT } T) \text{ AND } R \text{ AND } M$
Correct Answer: B) $W = (T \text{ AND } (\text{NOT } R)) \text{ OR } M$
Explanation: "Rain sensor is Dry" corresponds to $R = 0$, which is represented logically by $\text{NOT } R$. "High temperature" is $T$. Combining them gives $(T \text{ AND } (\text{NOT } R))$. Adding the manual override via an OR gate produces $(T \text{ AND } (\text{NOT } R)) \text{ OR } M$.
Question 7
Scenario: Study this array filtering algorithm:
Set Data = [12, 45, 68, 23, 89, 90, 34] Set Threshold = 50 Set Result = []  FOR EACH val IN Data:     IF (val > Threshold) AND (val % 2 == 0) THEN         Append val to Result     END IF END FOR
What values will be contained in Result at the end of execution?
A) [68, 89, 90]
B) [68, 90]
C) [45, 89]
D) [12, 68, 90, 34]
Correct Answer: B) [68, 90]
Explanation: The condition checks if the value is greater than 50 AND divisible by 2 (even).
- 68: $> 50$ and even (TRUE)

Question 8
Scenario: A web developer tests an e-commerce checkout function. The program executes without syntax errors, but when a user buys 3 items at \$10 each with a \$5 discount coupon, the system calculates a total cost of \$25 instead of \$25... wait, $3 \times 10 - 5 = 25$. However, when a user buys 2 items at \$20 each with a \$10 coupon, the system displays \$0 total cost!
Upon reviewing the code, the developer finds:
Total = Quantity * (Price - Coupon)
What type of error is present, and how should it be corrected?
A) Syntax Error; change Total to a floating-point string.
B) Logic Error; change the operator precedence to Total = (Quantity * Price) - Coupon.
C) Runtime Stack Overflow; clear the RAM memory.
D) Compiler Fault; reinstall the programming language environment.
Correct Answer: B) Logic Error; change the operator precedence to Total = (Quantity * Price) - Coupon.
Explanation: In the flawed code, the coupon discount is multiplied by quantity ($2 \times (20 - 10) = 20$, but if coupon was subtracted per item: $2 \times 10 = 20$). The intended business logic is to multiply item quantity by item price first, then subtract the single coupon: $(2 \times 20) - 10 = 30$. This is a classic logic error caused by incorrect placement of parentheses.
Question 9
Scenario: A Binary Search Tree (BST) stores integers. By definition, for any node, all values in its left subtree are smaller, and all values in its right subtree are larger.
If you insert the elements [50, 30, 70, 20, 40] in order into an empty BST, which element is the left child of node 30?
A) 50
B) 70
C) 20
D) 40
Correct Answer: C) 20
Explanation:
1. Insert 50 (Root).
2. Insert 30 ($30 < 50 \rightarrow$ goes left of 50).
3. Insert 70 ($70 > 50 \rightarrow$ goes right of 50).
4. Insert 20 ($20 < 50 \rightarrow$ goes left to 30; $20 < 30 \rightarrow$ goes left of 30).
Therefore, 20 is the left child of 30.
Question 10
Scenario: A multi-threaded operating system manages two processes ($P_1$ and $P_2$). $P_1$ locks File A and waits to access File B. Simultaneously, $P_2$ locks File B and waits to access File A. Neither process can proceed, freezing the system.
What is this state called in computer architecture?
A) Deadlock

Explanation: Deadlock occurs in concurrent systems when two or more execution threads are blocked indefinitely, each holding a resource the other needs.
Question 11
Scenario: A relational database table TRANSACTIONS contains columns: [TxID, UserID, Amount, Location, Status].
A fraud investigator runs this SQL query:
SELECT UserID, COUNT(TxID)  FROM TRANSACTIONS  WHERE Amount > 1000 AND Status = 'Flagged' GROUP BY UserID  HAVING COUNT(TxID) >= 3
What does this query retrieve?
A) All transactions greater than \$1,000 for any user.
B) Users who have at least 3 flagged transactions that each exceed \$1,000.
C) Users whose total transaction sum exceeds \$3,000.
D) Users who made exactly 3 transactions in total.
Correct Answer: B) Users who have at least 3 flagged transactions that each exceed \$1,000.
Explanation: The WHERE clause filters records with Amount > 1000 and Status = 'Flagged'. GROUP BY UserID aggregates these flagged transactions per user, and HAVING COUNT(TxID) >= 3 filters for users meeting the threshold of 3 or more such records.
Question 12
Scenario: Consider a hash table storing user records. When two different keys (e.g., username "alice" and "bob") produce the exact same index output when passed through the hash function, what occurs and how is it resolved?
A) A Hash Collision occurs; it is resolved using methods like Chaining or Open Addressing.
B) A Compiler Crash occurs; it is resolved by restarting the server.
C) An Encryption Error occurs; it is resolved by converting text to ASCII.
D) A Logic Overflow occurs; it is resolved by deleting both records.
Correct Answer: A) A Hash Collision occurs; it is resolved using methods like Chaining or Open Addressing.
Explanation: When distinct inputs yield identical hash indices, a hash collision takes place. Data structures manage collisions via linked-list chaining, linear probing, or open addressing strategies.
Question 13
Scenario: Examine this algorithm that checks if a string is a palindrome (reads the same forward and backward):
FUNCTION IsPalindrome(text):     Set left = 0     Set right = Length(text) - 1          WHILE left < right:         IF text[left] != text[right] THEN             RETURN False         END IF         Set left = left + 1         Set right = right - 1     END WHILE     RETURN True END FUNCTION
What is the time complexity of this algorithm in terms of string length $n$?
A) $O(n^2)$
B) $O(n)$
C) $O(\log n)$
D) $O(1)$
Correct Answer: B) $O(n)$
Explanation: The two pointers move toward the middle, comparing characters. At most, the loop runs $\frac{n}{2}$ times. In Big-O notation, constant factors are dropped, yielding linear time complexity $O(n)$.
Section 2: Deep Learning, AI System Architecture & Ethics
Question 14
Scenario: An AI development team trains a Convolutional Neural Network (CNN) to detect malignant skin lesions from medical photos. The model achieves 99% accuracy on training images, but drops to 61% accuracy on validation images from an external hospital.
What technique should engineers use to reduce this overfitting issue?
A) Add Dropout layers, apply Data Augmentation, and gather more diverse training samples.
B) Increase the learning rate to maximum speed.
C) Remove all hidden layers from the neural network.
D) Turn off the computer's graphics processing unit (GPU).
Correct Answer: A) Add Dropout layers, apply Data Augmentation, and gather more diverse training samples.
Explanation: Overfitting occurs when a neural network memorizes training set specifics instead of learning generalized features. Standard regularization techniques include Dropout (randomly deactivating neurons during training), Data Augmentation (flipping/rotating images), and training on more diverse datasets.
Question 15
Scenario: During the training of a Deep Neural Network using Gradient Descent, the error gradients become extremely tiny as they propagate backward through many hidden layers, causing the early layer weights to stop updating completely.
What is this fundamental deep learning issue called?
A) Exploding Gradient Problem
B) Vanishing Gradient Problem
C) Deadlock Conditions
D) Binary Compilation Error
Correct Answer: B) Vanishing Gradient Problem
Explanation: The Vanishing Gradient Problem occurs during backpropagation when small derivative values multiply repeatedly through deep network layers, causing early layer weights to change imperceptibly and halting learning.
