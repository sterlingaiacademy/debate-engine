Grade 10 Assessment: Computational Thinking and Artificial Intelligence
Instructions: Review each of the 25 questions below. The correct answer for each multiple-choice question is clearly marked, followed by a detailed explanation of the core concept.
Part 1: Computational Thinking
1. Decomposition
When creating a complex mobile application, a developer breaks down the project into smaller tasks: designing the user interface, setting up the database, and writing the underlying code. Which computational thinking principle is being demonstrated here?
	•	A) Abstraction
	•	B) Decomposition (Correct Answer)
	•	C) Pattern Recognition
	•	D) Algorithm Design
Explanation: Decomposition involves breaking down a complex problem or system into smaller, manageable, and more understandable parts to solve it effectively.
2. Pattern Recognition
A weather system analyzes temperature records from the past 50 years to identify recurring seasonal trends. Which skill is primarily used to spot these repeated trends?
	•	A) Abstraction
	•	B) Pattern Recognition (Correct Answer)
	•	C) Hardware Calibration
	•	D) Decomposition
Explanation: Pattern recognition involves finding similarities, trends, or repetitions among and within data sets to make predictions or solve problems.
3. Abstraction
A GPS map application displays roads, traffic levels, and estimated travel times, but hides underground water pipes and electrical lines. Why does the app hide this extra information?
	•	A) To apply abstraction by keeping only relevant details for navigation (Correct Answer)
	•	B) To decompose the map into separate pixels
	•	C) To run a pattern recognition check on driver behavior
	•	D) To prevent the GPS signal from disconnecting
Explanation: Abstraction focuses on filtering out unnecessary background details and focusing only on the features that are essential for the specific context.
4. Algorithmic Thinking
Which of the following best describes an algorithm?
	•	A) A physical component inside a computer CPU
	•	B) A step-by-step set of instructions to solve a specific problem (Correct Answer)
	•	C) A decorative graphic design layout
	•	D) A collection of random numbers generated by a machine
Explanation: An algorithm is a clearly defined, step-by-step procedure or set of rules followed to accomplish a specific task or solve a problem.
5. Searching Algorithms
You are looking for the word "Python" in a dictionary. Instead of checking every page from the beginning, you open the middle, see that "Python" comes after the current page, and eliminate the first half. Which search method does this represent?
	•	A) Linear Search
	•	B) Binary Search (Correct Answer)
	•	C) Random Search
	•	D) Exhaustive Search
Explanation: Binary search repeatedly divides a sorted dataset or list in half to quickly locate a target item, eliminating half of the remaining items in each step.
6. Sorting Algorithms
Consider the list of numbers: [5, 2, 8, 1, 3]. If you sort them in ascending order, what is the final sorted list?
	•	A) [8, 5, 3, 2, 1]
	•	B) [1, 2, 3, 5, 8] (Correct Answer)
	•	C) [2, 5, 1, 3, 8]
	•	D) [1, 3, 2, 5, 8]
Explanation: Ascending order means arranging values from the smallest number to the largest number (1, 2, 3, 5, 8).
7. Logic Conditions
An automated door opens ONLY IF a person approaches AND the emergency lock is OFF. In which scenario will the door open?
	•	A) A person approaches and the emergency lock is ON
	•	B) No person approaches and the emergency lock is OFF
	•	C) A person approaches and the emergency lock is OFF (Correct Answer)
	•	D) No person approaches and the emergency lock is ON
Explanation: The logical operator AND requires both individual conditions to evaluate as True simultaneously for the overall condition to be satisfied.
8. Debugging
A student writes a program to compute the average of three exam scores: 80, 90, and 100. The computer outputs 200 because the program calculated 80 + 90 + (100 / 3) instead of (80 + 90 + 100) / 3. What type of issue is this?
	•	A) A hardware failure in the monitor
	•	B) A logic error caused by incorrect operation order (Correct Answer)
	•	C) A network connection error
	•	D) A syntax error that prevents execution
Explanation: A logic error occurs when the code runs without crashing or displaying syntax errors, but produces an incorrect result due to faulty mathematical or programmatic reasoning.
9. Loops and Iteration
Examine the following pseudocode:
count = 0 REPEAT 4 TIMES:     count = count + 3 PRINT count 
What value is printed at the end?
	•	A) 4
	•	B) 7
	•	C) 12 (Correct Answer)
	•	D) 16
Explanation: The loop adds 3 to the variable count four times consecutively: 0 + 3 = 3 (iter 1), 3 + 3 = 6 (iter 2), 6 + 3 = 9 (iter 3), and 9 + 3 = 12 (iter 4).
10. Flowcharts
In standard flowchart diagrams, which symbol shape represents a decision point (e.g., checking an IF condition)?
	•	A) Oval
	•	B) Rectangle
	•	C) Diamond (Correct Answer)
	•	D) Circle
Explanation: Standard ISO/ANSI flowchart notation uses a diamond shape to signify a conditional branching logic check (such as Yes/No or True/False).
11. Data Representation
Computers store and process information using binary digits (bits). What are the two digits used in binary representation?
	•	A) 1 and 2
	•	B) 0 and 1 (Correct Answer)
	•	C) 0 and 10
	•	D) A and B
Explanation: Digital electrical systems use a base-2 number system composed entirely of 0s (OFF/Low Voltage) and 1s (ON/High Voltage).
12. Problem Generalization
After creating an algorithm to find the largest number in a list of 5 items, a student modifies it so it works for a list of 5,000 items without rewriting the core logic. This practice is known as:
	•	A) Generalization (Correct Answer)
	•	B) Hardcoding
	•	C) Syntax Formatting
	•	D) Overfitting
Explanation: Generalization adapts an existing solution or algorithm so it can solve a broader range or variable scale of similar problems.
13. Variables and Assignment
Examine the following code lines executed in order:
x = 10 y = 5 x = x + y y = x - y 
What are the values of x and y after these statements execute?
	•	A) x = 10, y = 5
	•	B) x = 15, y = 10 (Correct Answer)
	•	C) x = 15, y = 5
	•	D) x = 5, y = 10
Explanation: Step 1: x becomes 10 + 5 = 15. Step 2: y becomes 15 - 5 = 10. Thus, at the end, x = 15 and y = 10.
Part 2: Artificial Intelligence & Machine Learning
14. Definition of AI
Which statement best defines Artificial Intelligence (AI)?
	•	A) Hardware components designed to protect computers from physical damage
	•	B) Systems or machines that perform tasks typically requiring human intelligence (Correct Answer)
	•	C) High-speed internet cables connecting international networks
	•	D) Manual software spreadsheets used for accounting
Explanation: AI refers to computer systems that simulate cognitive functions associated with human minds, such as problem-solving, perception, learning, and reasoning.
15. Machine Learning Basics
How does a Machine Learning model improve its performance on a task over time?
	•	A) By replacing physical memory chips inside the motherboard
	•	B) By learning from data and experience without being explicitly reprogrammed for every rule (Correct Answer)
	•	C) By increasing monitor screen resolution
	•	D) By requiring humans to write more lines of manual code every day
Explanation: Machine Learning is a branch of AI focused on building applications that automatically learn and improve performance from data experience rather than explicit step-by-step programming.
16. Supervised vs. Unsupervised Learning
A model is trained using thousands of pictures that are explicitly tagged as either "Dog" or "Cat". What type of machine learning is this?
	•	A) Unsupervised Learning
	•	B) Supervised Learning (Correct Answer)
	•	C) Manual Rules-Based Programming
	•	D) Random Learning
Explanation: Supervised learning uses labeled training datasets where input data is paired with the correct output label to teach algorithms how to classify unseen inputs.
17. Training Data Quality
If a facial recognition model is trained using photos taken only in bright daylight, what is the most likely outcome when tested in low-light conditions?
	•	A) It will automatically turn on light sources in the room
	•	B) It may perform poorly because its training dataset lacked low-light examples (Correct Answer)
	•	C) It will perform perfectly regardless of lighting conditions
	•	D) It will permanently delete its training parameters
Explanation: AI models rely entirely on the quality and diversity of their training datasets. If specific operational scenarios are omitted, performance drops when encountering those conditions.
18. Natural Language Processing (NLP)
Which application relies primarily on Natural Language Processing (NLP)?
	•	A) Adjusting computer fan speed based on system temperature
	•	B) Translating text from English to Spanish automatically (Correct Answer)
	•	C) Sorting physical mail using mechanical belt drives
	•	D) Calculating monthly bank interest rates
Explanation: Natural Language Processing (NLP) is the branch of AI dedicated to helping computers understand, interpret, process, and generate human written or spoken language.
19. Computer Vision
Self-driving cars use cameras and sensors to detect pedestrians, lanes, and road signs. Which subfield of AI enables machines to interpret visual information from images or video?
	•	A) Computer Vision (Correct Answer)
	•	B) Speech Synthesis
	•	C) Database Indexing
	•	D) Quantum Encryption
Explanation: Computer Vision is a field of artificial intelligence that trains computers to interpret, understand, and extract meaningful information from digital images and videos.
20. AI Ethics: Bias
An automated hiring AI consistently prefers candidates from one demographic group over others because the historical training data contained past human hiring biases. This issue is called:
	•	A) Algorithmic Bias (Correct Answer)
	•	B) Data Encryption
	•	C) System Overclocking
	•	D) High Bandwidth
Explanation: Algorithmic bias occurs when an AI system produces systematically prejudiced results due to flawed assumptions, skewed training data, or historical human biases embedded within the data.
21. Neural Networks
Artificial Neural Networks (ANNs) are machine learning models loosely inspired by which biological structure?
	•	A) The human circulatory system
	•	B) The human brain and network of neurons (Correct Answer)
	•	C) Plant photosynthesis pathways
	•	D) DNA double-helix structures
Explanation: ANNs consist of interconnected processing units structured in layers that mirror the interconnected network of biological biological neurons in human brains.
22. Generative AI
Tool systems like ChatGPT or Midjourney create new essays, images, or audio tracks based on learned patterns. What category of AI do these tools belong to?
	•	A) Generative AI (Correct Answer)
	•	B) Symbolic AI
	•	C) Database Backup AI
	•	D) Mechanical AI
Explanation: Generative AI refers to algorithms capable of producing new original text, images, videos, audio, or synthetic data based on patterns learned from training data.
23. Turing Test
What is the classic purpose of the Turing Test proposed by Alan Turing?
	•	A) To test the physical battery life of modern laptops
	•	B) To evaluate whether a machine can exhibit intelligent behavior indistinguishable from a human (Correct Answer)
	•	C) To measure the maximum network download speed of a computer
	•	D) To check for physical errors on a hard drive surface
Explanation: Introduced by Alan Turing in 1950, the Turing Test checks whether an evaluator can reliably distinguish between natural human text conversation and artificial conversational response.
24. AI Ethics: Privacy
A smart home voice assistant listens continuously to record conversations and sell consumer preference data to third parties without user consent. Which ethical concern is raised here?
	•	A) Data Privacy and User Consent (Correct Answer)
	•	B) High Electricity Costs
	•	C) Hardware Wear and Tear
	•	D) Slow Processing Speeds
Explanation: Gathering personal audio streams and user interactions without explicit permission violates user privacy rights and fundamental data governance standards.
25. Rule-Based vs. Learning Systems
A traditional computer program follows strict, hardcoded "IF-THEN" rules written directly by a human. How does a Machine Learning model differ?
	•	A) It cannot run on standard electronic computers
	•	B) It automatically learns patterns and relationships directly from data (Correct Answer)
	•	C) It requires zero electricity to execute tasks
	•	D) It never makes mistakes under any conditions
Explanation: Traditional programs follow explicitly crafted manual logic rules, whereas Machine Learning models examine data to learn mathematical weights, parameters, and relationships on their own.
