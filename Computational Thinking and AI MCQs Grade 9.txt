Question 1
Scenario: An engineer is developing a real-time GPS navigation application. To model the road network, intersections are represented as vertices and roads as weighted edges. When computing the shortest path between two distant cities, evaluating every simple path would take $O(V!)$ exponential time. Instead, the engineer uses A* Search algorithm with an admissible heuristic function.
Which computational thinking process is being used when converting a real physical road network into a weighted graph and applying a heuristic search to solve an otherwise intractable problem?
A) Structural Decomposition & Heuristic Abstraction
B) Syntax Compilation & Parallel Memory Mapping
C) Hardware Paging & Virtual Cache Loading
D) Lexical Analysis & Recursion Unrolling
Correct Answer: A) Structural Decomposition & Heuristic Abstraction
Explanation: Abstraction converts complex physical geography into a graph data structure (vertices/edges), stripping away irrelevant physical features. Heuristic search optimizes graph traversal by focusing search direction towards the goal without exhaustively evaluating exponential paths.

Question 3
Scenario: Compare the worst-case time complexity of searching for an element in an unsorted array of size $n$ versus searching in a balanced Binary Search Tree (BST) of size $n$:
	•	Unsorted Array Linear Search: $O(n)$
	•	Balanced BST Search: $O(\log_2 n)$
If $n = 1,048,576$ elements, approximately how many operations does the balanced BST search take in the worst case compared to the linear search?
A) BST takes ~20 operations, while linear search takes ~1,048,576 operations.
B) BST takes ~1,000 operations, while linear search takes ~20 operations.
C) Both take approximately 1,048,576 operations.
D) BST takes ~524,288 operations, while linear search takes ~1,000 operations.
Correct Answer: A) BST takes ~20 operations, while linear search takes ~1,048,576 operations.
Explanation: $\log_2(1,048,576) = 20$ because $2^{20} = 1,048,576$. In the worst case, a balanced BST eliminates half the tree at each step, requiring only 20 comparisons versus $1,048,576$ comparisons for linear search.
Question 4
Scenario: Trace the output of the following recursive function:
FUNCTION FastPower(base, exp):     IF exp == 0 THEN         RETURN 1     ELSE IF exp % 2 == 0 THEN         Set half = FastPower(base, exp / 2)         RETURN half * half     ELSE         RETURN base * FastPower(base, exp - 1)     END IF END FUNCTION  OUTPUT FastPower(2, 6)
What is the return value of FastPower(2, 6) and its logarithmic recurrence property?
A) 64; computed in $O(\log_2 \text{exp})$ recursive calls.
B) 32; computed in $O(\text{exp})$ recursive calls.
C) 128; computed in $O(\text{exp}^2)$ recursive calls.
D) 64; computed in $O(1)$ recursive calls.
Correct Answer: A) 64; computed in $O(\log_2 \text{exp})$ recursive calls.
Explanation: $2^6 = 64$. The function uses exponentiation by squaring: FastPower(2, 6) calls FastPower(2, 3) $\rightarrow$ FastPower(2, 2) $\rightarrow$ FastPower(2, 1) $\rightarrow$ FastPower(2, 0). This reduces exponentiation time complexity from $O(n)$ to $O(\log n)$.

Enqueue(PrintQueue, "Doc1") Enqueue(PrintQueue, "Doc2") Push(UndoStack, "Edit1") Push(UndoStack, "Edit2")  Set Job = Dequeue(PrintQueue) Set Action = Pop(UndoStack)
What are the values of Job and Action?
A) Job = "Doc1", Action = "Edit2"
B) Job = "Doc2", Action = "Edit1"
C) Job = "Doc1", Action = "Edit1"
D) Job = "Doc2", Action = "Edit2"
Correct Answer: A) Job = "Doc1", Action = "Edit2"

Question 9
Scenario: Consider a hash table with 10 slots using the hash function $H(k) = k \bmod 10$. Keys are inserted in this order: 23, 43, 13. Using linear probing ($H(k, i) = (H(k) + i) \bmod 10$) to resolve collisions, at which array index will key 13 be stored?
A) Index 5
B) Index 3
C) Index 4
D) Index 6
Correct Answer: A) Index 5
Explanation:
- Insert 23: $23 \bmod 10 = 3$ (Slot 3 is free $\rightarrow$ place at 3).
- Insert 43: $43 \bmod 10 = 3$ (Slot 3 occupied $\rightarrow$ probe slot $(3+1)\bmod 10 = 4$, free $\rightarrow$ place at 4).
- Insert 13: $13 \bmod 10 = 3$ (Slot 3 occupied $\rightarrow$ probe slot 4 occupied $\rightarrow$ probe slot $(3+2)\bmod 10 = 5$, free $\rightarrow$ place at 5).
Question 10
Scenario: Two processes $P_1$ and $P_2$ share resources $R_1$ and $R_2$. $P_1$ acquires $R_1$ and requests $R_2$. $P_2$ acquires $R_2$ and requests $R_1$. Neither process yields its held resource.
What four Coffman conditions define this state, and how can it be prevented?
A) Mutual Exclusion, Hold & Wait, No Preemption, Circular Wait; prevented by breaking Circular Wait (ordering resource acquisition).
B) Compilation, Execution, Linking, Loading; prevented by restarting the server.
C) Encryption, Decryption, Hashing, Salting; prevented by increasing key length.
D) Overfitting, Underfitting, Bias, Variance; prevented by gathering more data.
Correct Answer: A) Mutual Exclusion, Hold & Wait, No Preemption, Circular Wait; prevented by breaking Circular Wait (ordering resource acquisition).
Explanation: A deadlock requires all four Coffman conditions. Eliminating any single condition (e.g., enforcing a strict global ordering on resource acquisition to eliminate circular wait) prevents deadlocks.
Question 11
Scenario: A database administrator writes an SQL query to find high-value customers from a database table ORDERS with columns [OrderID, CustomerID, TotalAmount, Status]:
SELECT CustomerID, SUM(TotalAmount) AS LifetimeValue FROM ORDERS WHERE Status = 'Completed' GROUP BY CustomerID HAVING SUM(TotalAmount) > 10000
What is the precise execution order of clauses in this SQL query?
A) FROM $\rightarrow$ WHERE $\rightarrow$ GROUP BY $\rightarrow$ HAVING $\rightarrow$ SELECT
B) SELECT $\rightarrow$ FROM $\rightarrow$ WHERE $\rightarrow$ GROUP BY $\rightarrow$ HAVING
C) WHERE $\rightarrow$ FROM $\rightarrow$ HAVING $\rightarrow$ GROUP BY $\rightarrow$ SELECT
D) FROM $\rightarrow$ GROUP BY $\rightarrow$ HAVING $\rightarrow$ WHERE $\rightarrow$ SELECT
Correct Answer: A) FROM $\rightarrow$ WHERE $\rightarrow$ GROUP BY $\rightarrow$ HAVING $\rightarrow$ SELECT

Question 13
Scenario: An algorithm evaluates arithmetic expressions using Dijkstra's Two-Stack algorithm. For the expression ((3 + 5) * (10 - 2)), numbers are pushed onto an Operand Stack and operators onto an Operator Stack.
What is the maximum height reached by the Operand Stack during evaluation?
A) 2
B) 4
C) 8
D) 1
Correct Answer: A) 2
Explanation: In sub-expression (3 + 5), 3 and 5 are pushed (stack height 2), evaluated to 8 (stack height 1). In sub-expression (10 - 2), 10 and 2 are pushed alongside 8 (stack height reaches 2 after pushing 10, then 2 evaluates with 10 $\rightarrow$ 8). The maximum number of simultaneous un-evaluated operands on the stack is 2.
Section 2: AI Architectures, Machine Learning Engineering & Ethics
Question 14
Scenario: A computer vision model trained to diagnose chest X-rays achieves 98% overall accuracy on a dataset where 98% of images are healthy and 2% show disease. When deployed in a clinic, it fails to detect a single sick patient.
Why did high overall accuracy fail, and which evaluation metric should be used instead?
A) Class Imbalance Problem; evaluation should use Recall / Sensitivity and $F_1$-score instead of Accuracy.
B) Overclocking Error; evaluation should use GPU clock speed.
C) Syntax Errors; evaluation should use compiler logs.
D) Lossy Compression; evaluation should use image resolution.
Correct Answer: A) Class Imbalance Problem; evaluation should use Recall / Sensitivity and $F_1$-score instead of Accuracy.
Explanation: In severely imbalanced datasets, a naive model that predicts "Healthy" for every image achieves 98% accuracy while being completely useless. Recall ($\frac{\text{True Positives}}{\text{True Positives} + \text{False Negatives}}$) measures the proportion of actual positive cases correctly identified.
Question 15
Scenario: A deep learning model uses Gradient Descent to minimize a loss function. During training, the weight updates oscillate wildly back and forth across a steep valley without reaching the global minimum.
What hyperparameter adjustment or optimizer enhancement resolves this instability?
A) Reduce the Learning Rate or add Momentum (e.g., using the Adam optimizer).
B) Increase the Learning Rate to maximum.
C) Remove all training data.
D) Convert model weights to integer strings.
Correct Answer: A) Reduce the Learning Rate or add Momentum (e.g., using the Adam optimizer).
Explanation: A learning rate that is too high causes gradient descent to overshoot the minimum and diverge/oscillate. Adding momentum smooths out gradient updates by incorporating a moving average of past gradients.
Question 16
Scenario: An AI system plays a complex strategy game using Reinforcement Learning. The agent must choose between taking actions that exploit known high-reward strategies versus exploring unfamiliar actions that might yield even higher long-term rewards.
What foundational RL dilemma does this scenario describe, and what policy manages it?
A) Exploration vs. Exploitation Trade-off; managed by $\epsilon$-Greedy policies.
B) Supervised vs. Unsupervised Learning; managed by Linear Regression.
C) Overfitting vs. Underfitting; managed by Data Deletion.
D) Hardware vs. Software Constraints; managed by CPU Paging.
Correct Answer: A) Exploration vs. Exploitation Trade-off; managed by $\epsilon$-Greedy policies.
Explanation: The exploration-exploitation trade-off balances choosing actions known to give good rewards (exploitation) against trying new actions to discover better outcomes (exploration). An $\epsilon$-greedy policy explores with probability $\epsilon$ and exploits with probability $1 - \epsilon$.
